# Translations

Details and commands: `freecad/nxt/resources/translations/README.md`.

## Marking text

- Python: `translate("Nxt", "Text")` with **literal** arguments, so
  lupdate can find them. Commands use `QT_TRANSLATE_NOOP("<CommandName>",
  ...)` in `GetResources`.
- QML: `qsTr("Text")`; the context is the file's name.
- Templates: nothing to do. Titles, hints, labels, `labels` and `choices`
  are extracted by `scripts/i18n.py update` into `NxtTemplate`, with the
  template id as the disambiguation, and shown through `template_text`.
- Report-view and console messages are for developers and aren't
  translated.
- Placeholders: `%1` in QML, `%s`/`%d` or `{}` in Python. Never build a
  sentence from translated fragments; translate the whole sentence with
  placeholders.

## FreeCAD's words first

`translate` returns FreeCAD's own translation when FreeCAD has the same
term (`app/freecad_terms.py`, generated by `scripts/i18n.py terms`), also
for "Nxt <term>". Nxt's `.ts` files still translate every string, as the
fallback when a FreeCAD language lacks the term.

## Changing language while FreeCAD runs

FreeCAD switches language live. Anything built from translated text must
follow:

- QML views made by `quick_host.make_view` and widgets passed to
  `i18n.follow(widget)` are retranslated automatically.
- Python-built models (inspector cards, tree rows) register a refresh with
  `i18n.on_change(self.refresh)`.
- Never cache translated text beyond what `i18n` clears.

## Writing translations

- **Brevity**: labels, menus, buttons and settings as short as the
  language allows. Avoid long compounds (German) where a shorter phrase
  exists. Tooltips may be full sentences.
- Use FreeCAD's established term in that language for FreeCAD concepts.
- Keep "FreeCAD", "Nxt", workbench names and FreeCAD's quoted error
  messages as they are.
- File names use FreeCAD's language codes: `Nxt_de.ts`, `Nxt_es-ES.ts`,
  `Nxt_zh-CN.ts`. Anything else never loads.
- After editing a `.ts`: `python scripts/i18n.py build`, then
  `check --locale <code>`. The tests fail if a `.qm` doesn't match its
  `.ts` or a placeholder was lost.
